## Card images

In the editor, use **Add image** under either the term or definition. Images can accompany text or be used alone in flashcards and Match. Add text for answers used in written, multiple-choice, or dictation tests.

PNG, JPEG, WebP, and GIF files up to 10 MB are accepted. Images are resized to at most 1280 pixels and stored as compressed JPEGs (GIFs become still images). Very detailed images may need cropping. Press **Save** to keep edits in this browser on this device; clearing site data removes local cards and images.

Single-set and all-set JSON exports embed images and restore them on import. Combining, duplicating, and swapping cards preserve their images. For sets containing images, Share downloads JSON instead of creating an oversized link. Export backups regularly; browser storage is limited and failed saves leave edits unsaved.

Images count toward the existing Firebase cloud document limit. Local saving and JSON exports do not require cloud sync.
